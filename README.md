# منبه الصلاة

تطبيق ويب لعرض أوقات الأذان والإقامة في ولايات سلطنة عُمان، بواجهة عربية طولية
(9:16) تعمل مباشرة في المتصفح على الجوال والكمبيوتر.

## المزايا

- ساعة رقمية بالثواني ونظام 12/24 ساعة.
- التاريخ الهجري (قابل للتعديل) والميلادي واسم اليوم.
- أوقات الأذان والإقامة للصلوات الخمس والشروق، مع تظليل الصلاة القادمة.
- عدّاد تنازلي بين الأذان والإقامة.
- أذان صوتي كامل عند دخول الوقت، ونغمة قصيرة عند الإقامة.
- تحديد الولاية تلقائياً عبر GPS (يحتاج HTTPS).
- إشعارات المناسبات الدينية في الشريط المتحرك.
- حفظ الإعدادات في المتصفح (فوارق الإقامة، الصوت، مستوى الصوت، التاريخ الهجري).
- يعمل بدون إنترنت بعد أول تحميل، وقابل للتثبيت على الشاشة الرئيسية (PWA).

## أوقات الصلاة

الأوقات تُقرأ من جداول سنوية لكل ولاية مطابقة لتقويم وزارة الأوقاف والشؤون
الدينية في سلطنة عُمان، محفوظة في مجلد `times/` (94 ولاية × 366 يوماً).
عند تعذر قراءة الجدول يتحول التطبيق تلقائياً إلى حساب فلكي احتياطي.

### تحديث التقويم

```bash
python update_times.py
```

يُنزّل جداول كل الولايات ويولّد `times_data.js` (نسخة مدمجة تعمل بلا خادم)
و`times_pack.js` (نسخة مضغوطة). شغّله عند صدور تقويم سنة جديدة.

## التشغيل محلياً

```bash
python -m http.server 8130
```

ثم افتح `http://localhost:8130`.

## البنية

| الملف | الوصف |
| --- | --- |
| `index.html` | التطبيق كاملاً (واجهة + منطق) |
| `times/` | جداول أوقات الصلاة لكل ولاية |
| `times_data.js` | جداول كل الولايات مدمجة في ملف واحد |
| `sounds/` | ملفات الأذان |
| `sw.js` | Service Worker للعمل بدون إنترنت |
| `manifest.webmanifest` | بيانات التثبيت على الأجهزة |
| `update_times.py` | سكربت تحديث التقويم |
